# SmartDeliveryOps

AI-Powered Self-Healing DevOps & Smart Delivery Management Platform

## Project Objective

SmartDeliveryOps is a Final Year Project that combines:

- AI
- DevOps
- Docker
- Kubernetes
- Jenkins CI/CD
- Prometheus
- Grafana
- PostgreSQL
- Ollama
- Terraform
